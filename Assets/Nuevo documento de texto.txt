Si deseas trabajar con un grafo de estados en Unity, y estás buscando una solución **por defecto** que ya venga integrada en Unity, puedes utilizar el **Animator Controller** con un **State Machine** visual, que es una herramienta muy poderosa para manejar transiciones de estados (por ejemplo, animaciones). Aunque el `Animator` generalmente se asocia con animaciones, se puede adaptar para gestionar lógica de estado en el comportamiento de los objetos.

### **Usando el Animator Controller en Unity**

El **Animator Controller** de Unity te permite crear un **grafo de estados** visualmente, definir transiciones entre ellos y controlar las condiciones para que esos estados cambien. Esta herramienta es ideal para situaciones donde quieres representar comportamientos complejos mediante estados visuales, pero también puedes usarla para gestionar lógica no relacionada con animaciones, como cambiar entre "Idle", "Walking", "Jumping", "Attacking", etc.

#### ¿Qué es el Animator Controller?

- El **Animator Controller** es un recurso que te permite organizar los **estados de animación** y las **transiciones** entre estos estados. Se utiliza principalmente para animaciones, pero puedes usarlos también para gestionar el flujo de comportamiento de un objeto (por ejemplo, un personaje).
  
- **State Machine** es el grafo visual de estados en el que puedes definir transiciones, condiciones y animaciones asociadas.

### Pasos para crear una máquina de estados visual con Animator:

1. **Crear un Animator Controller**:
   - Ve a la ventana del Proyecto en Unity y haz clic derecho en la carpeta donde quieras crear el controlador de animación (por ejemplo, en la carpeta **"Assets"**).
   - Selecciona **Create** → **Animator Controller**.
   - Asigna un nombre a este Animator Controller, por ejemplo, "PlayerAnimatorController".

2. **Asignar el Animator Controller al GameObject**:
   - Selecciona el GameObject al que deseas agregar la máquina de estados (por ejemplo, el jugador o enemigo).
   - En el Inspector, agrega el componente **Animator** si no lo tiene.
   - En el campo **Controller** del Animator, asigna el Animator Controller que acabas de crear (el que llamaste "PlayerAnimatorController").

3. **Abrir la ventana de Animator**:
   - Haz doble clic en el Animator Controller que acabas de crear. Esto abrirá la ventana **Animator** donde puedes visualizar y editar el grafo de estados.
   
4. **Añadir Estados**:
   - En el grafo del Animator, puedes **crear estados** (representados por nodos) haciendo clic derecho en la ventana de Animator y seleccionando **Create State** → **Empty** o seleccionando una animación existente.
   - Para añadir una animación, crea un **Animator Clip** (si no tienes uno), luego arrástralo al nodo del estado en el grafo.

5. **Definir Transiciones**:
   - Haz clic derecho sobre un estado y selecciona **Make Transition** para crear una transición entre este estado y otro. Puedes añadir múltiples transiciones entre los estados para definir cómo se deben mover de uno a otro.
   - Las transiciones pueden depender de **parámetros** como booleans, enteros, flotantes o triggers. Por ejemplo, si quieres que tu personaje pase de "Idle" a "Walk" cuando el jugador presione una tecla, puedes usar un parámetro booleano como "IsWalking".

6. **Agregar Parámetros**:
   - Los **parámetros** te permiten controlar las transiciones entre los estados. Por ejemplo:
     - Haz clic en el **Panel de parámetros** en la ventana **Animator**.
     - Crea parámetros como `bool`, `float`, `int` o `trigger`. Ejemplo: crear un parámetro **"IsWalking"** de tipo **bool**.
   
7. **Configurar Transiciones**:
   - En las transiciones entre estados, puedes agregar condiciones para que la transición ocurra. Por ejemplo, puedes hacer que el personaje pase de "Idle" a "Walking" cuando el parámetro **"IsWalking"** sea verdadero:
     - Selecciona la transición entre los estados en el grafo y, en el **Inspector**, agrega una condición que dependa del parámetro `IsWalking`.
     - Si el parámetro `IsWalking` es **true**, la transición se activará.

8. **Controlar el Animator desde el Script**:
   Para cambiar de estado desde el código (por ejemplo, para que el personaje camine cuando presiona una tecla), puedes modificar los parámetros del Animator desde tu script C#:

   ```csharp
   using UnityEngine;

   public class PlayerController : MonoBehaviour
   {
       private Animator animator;

       void Start()
       {
           animator = GetComponent<Animator>(); // Obtener el componente Animator
       }

       void Update()
       {
           // Detectar si el jugador presiona una tecla para caminar
           bool isWalking = Input.GetKey(KeyCode.W);

           // Cambiar el parámetro del Animator
           animator.SetBool("IsWalking", isWalking);  // Cambiar a "Walking" si W está presionado
       }
   }
   ```

   Aquí, cuando el jugador presiona **W**, el parámetro `IsWalking` se pone en **true**, lo que hará que la máquina de estados en el **Animator** cambie de "Idle" a "Walking".

### Resumen:

- El **Animator Controller** de Unity tiene una **máquina de estados visual** que te permite definir estados (por ejemplo, Idle, Walking, Attacking) y transiciones entre ellos basadas en parámetros.
- Puedes asignar el Animator Controller a un GameObject, luego desde un **script** controlar esos estados a través de parámetros, lo que hace que el objeto cambie de estado de manera fluida.
- Aunque se usa principalmente para animaciones, este sistema es flexible y puede adaptarse a cualquier tipo de lógica de comportamiento donde desees gestionar estados de manera visual.

### ¿Cuándo usar esta opción?

Si tu objetivo principal es manejar **animaciones** o estados simples de comportamiento (como cambios de animación, desplazamiento entre estados de un personaje), el **Animator Controller** es una solución perfecta. Si tienes algo más complejo o necesitas más control sobre la lógica, entonces puede ser más adecuado implementar una máquina de estados personalizada como la que te mencioné antes.
